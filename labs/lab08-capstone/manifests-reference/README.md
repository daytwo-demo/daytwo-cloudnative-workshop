# Referencia consolidada (solo instructor)

Este directorio **no existe en el branch `main`**, solo en `solution`,
como referencia del instructor tras integrar las ocho capas. Reúne, en un
solo lugar, la versión final de cada manifiesto trabajado a lo largo de
la semana (uno por archivo, mismo contenido que el `# SOLUCIÓN` de su lab
de origen).

**No es para copiar y pegar en el capstone.** El objetivo del lab08 es que
cada equipo lo arme de memoria: usar esto como respuesta antes de
intentarlo derrota el propósito del lab. Sirve para que el instructor
valide rápido si un equipo se trabó en algo puntual, o para dar el
`git diff lab08-start lab08-solution` completo a quien lo pida al cierre
del workshop.
